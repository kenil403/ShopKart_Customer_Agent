# ShopKart – Returns Policy Update
Effective: 1 March 2026
This update replaces the return window and pickup charge rules in all earlier return policies. All other rules in earlier policies remain unchanged unless stated below.

## 1. New Return Window
- Clothing, footwear, home and kitchen: **15 days** from delivery
- Electronics and accessories: **10 days** from delivery, and only for defective, damaged or wrong items (not for change of mind)

## 2. Damaged or Defective Items
If an item arrives damaged, the customer must report it within 48 hours of delivery with at least one photo. Damaged-item returns reported after 48 hours are handled under the normal return window for that category.

## 3. Return Pickup Charges
Return pickup is now **free for all eligible returns**. The earlier ₹50 pickup fee no longer applies.

## 4. Sale Items
Items bought during a clearance sale (marked "Final Sale" on the product page) cannot be returned or exchanged.
