# ShopKart – Returns & Exchange Policy
Effective: 1 April 2024

## 1. Return Window
Most items can be returned within **7 days** of delivery. The item must be unused, with original tags and packaging.

## 2. Non-Returnable Items
- Innerwear, lingerie and socks
- Personal care and beauty products (opened)
- Customised or personalised products
- Gift cards

## 3. How to Request a Return
Go to My Orders, select the item, and click "Request Return". A pickup will be scheduled within 2 business days.

## 4. Exchanges
Exchanges are available for size issues on clothing and footwear only, within the same 7-day window, subject to stock availability.

## 5. Return Pickup Charges
Return pickup is free for defective or wrong items. For all other returns, a pickup fee of ₹50 is deducted from the refund.
